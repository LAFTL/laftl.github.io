## Publishing

GitHub Pages serves the root of the `main` branch. No build step or external runtime dependencies are required. `.nojekyll` preserves the static files.

## Accessibility

Semantic sections, visible keyboard focus, keyboard-operated example tabs, responsive layouts and reduced-motion support. Screen typography is Arial 18px body and 20px headings.
