The filing job

Saving email by hand means saving both the message and its attachments, then keeping them together. This script handles those steps.

How it works

I wrote the filing script and the code that schedules it. It checks for files that already exist and uses a lock so two runs don't overlap.

The repository also includes tests. The example here uses made-up content, not real emails.
